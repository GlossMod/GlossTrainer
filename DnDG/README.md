# DnDG · GlossTrainer

## 原生 ASI 1.0.0

面向 Windows Steam x64 版 **Dungeons & Degenerate Gamblers 2.0.8.1**，使用 C++20、Dear ImGui、MinHook 与 Ultimate ASI Loader。在 [DnDG v1.0.0](https://github.com/GlossMod/GlossTrainer/releases/tag/DnDG%2Fv1.0.0) 下载 Windows 安装包，按[安装指南](docs/release-readme.md)配置 ASI 与游戏线程桥接，再从 Steam 启动。修改器使用独立的游戏存档目录。

进入普通对局后按 **Insert** 打开面板。源码构建与隔离测试见[开发指南](docs/native.md)，验证范围见[验证记录](docs/verification.md)。

## 历史：v0.1.4 Godot/GDScript 资源包原型

适配 Windows Steam 版 **Dungeons & Degenerate Gamblers 2.0.8.1**。当前目录保留 **v0.1.4 的 Godot/GDScript 资源包原型**，不覆盖 Steam 安装。CE 仅用于核对进程与版本。

> 此原型不是仓库要求的 C++ / Dear ImGui / MinHook / Ultimate ASI Loader 版本，不生成 `GlossTrainer.asi`。下方启动说明仅适用于原型。

### 启动

需要 Python 3.11+ 和已安装、拥有的 Steam 游戏。请先退出正在运行的 DnDG，保留 Steam 登录状态。下面的命令从仓库根目录运行：

```powershell
py -3 -B DnDG/tools/build.py --game-dir '<Steam 游戏安装目录>' --output output/dndg-local
py -3 -B output/dndg-local/bundle/launch.py
```

进入普通对局，等到玩家可操作时按 **Insert**。修改器打开时暂停游戏，关闭后恢复先前暂停状态。面板默认位于右上角，使用紧凑的横向导航和《影之刃零》《黑神话：悟空》同系的金色强调色。可在“设置”切换亮色/暗色、中英文并修改快捷键；默认跟随游戏语言。修改器默认使用本机的微软雅黑（含悬停提示），未安装则沿用游戏字体；不更改游戏原版字体或画面缩放。“关于”区可手动检查 GitHub 中 DnDG 专属标签的更新。

按住面板标题栏可移动窗口，拖拽右下角的斜线手柄可调整宽度和高度。如果想向右继续加宽，先把窗口向左移，为手柄留出空间。用 **Insert** 收起后，只要没有退出游戏，重新打开会保留位置和尺寸。

- **默认使用独立存档**：`%APPDATA%/GlossTrainer/DnDG/<bundle-id>/`，首次启动不会载入原版存档；同一个构建再次启动会恢复修改器设置。不同输出路径或脚本版本会生成不同的存档目录。
- Steam 的正常校验保持不变。若独立副本不能通过校验或重定向回原版，不要替换 Steam 文件或尝试绕过。
- 构建不会覆盖已经存在的 `bundle/`。重建请指定新的 `--output`。**生成包含原版文件，仅供本机使用，勿分发**；可分发的内容是修改器脚本和本地构建工具。
- 想回原版时，从 Steam 正常启动即可；无需卸载或修复游戏。

### 可用操作

| 面板 | 操作 |
| --- | --- |
| 玩家 | 输入当前生命（1 到当前上限）、护盾（0–999）或筹码（0–9999），点「应用」或按 Enter 提交；也可一键回满生命。 |
| 卡牌 | 袖牌与桌面牌分开显示原版牌面。悬停查看详情，右键选择「丢弃／更换／添加」；也可点 `+` 添加。添加或更换时支持按名称或 ID 搜索。锁定/盖着的牌和正在遮蔽的牌局不允许编辑。 |
| 道具 | 切换「幸运护符」或「独特筹码」，点击网格图标立即添加；右键已获得的图标可移除或更换。独特筹码是有各自效果的道具，不是额外货币。 |
| 显示下一张牌 | 打开开关后收起面板，普通对局中左上角显示下一张牌的名称。悬停牌名查看效果。只读取玩家堆顶，不翻牌、不耗牌、不触发游戏原版预见。没有可读牌时不显示。 |

牌和道具是按游戏 ID 替换，不直接改底层效果参数。新增牌进入本局牌组，替换和移除也会影响对应牌组条目；对局结束后仍由游戏本身决定保存。添加牌不会补放“抽到/打出”效果；添加道具不会重新运行开局或奖励领取事件。每日挑战和高额赌局不提供修改或预览。

验证范围见 [验证记录](docs/verification.md)，构建格式与隔离细节见 [工具说明](tools/README.md)。
