# 影之刃零 · GlossTrainer v1.2.0

适配 **Windows x64 / CL-302256_JKS-17280**。支持的 `platform/steam/PBZ.exe` SHA-256：`4415933ce33476f14c837abb61a1b60af8b78cd81783896501913a7aac69e423`。其他游戏构建会禁用原生调用，请使用对应历史版本的修改器。

## 新增功能

- **免费随意传送**：地图传送不再消耗穿行符。
- **移除传送限制**：允许在铃铛附近等原本受限的位置，传送到已激活的铃铛；与免费传送分别控制。
- **自动收集战利品**：靠近受支持的掉落物、纸条和宝箱时自动交互，默认 **10 米**，可用滑块调整为 **1–50 米**。角色忙碌或战斗中会等待合适的交互状态。
- **高亮附近战利品**：使用游戏原生绿色光晕、物品图标和距离提示，可隔墙查看。默认 **50 米**，滑块可调 **1–100 米**。识别到单一种类的实际奖励时使用对应物品图，未知或多种奖励保留通用收藏标记；已开启宝箱从高亮和自动收集候选中排除。
- **相机调节**：支持视野 FOV、相机距离和垂直偏移，关闭后恢复原值；相机距离仍受当前游戏相机模式约束。
- **全部饰品生效**：应用背包中未装备饰品的效果，关闭时只撤销修改器添加的效果。

两项距离滑块位于“修改功能 → 资源”。拖动后点击各自的“应用”提交，成功应用的距离与开关状态会保存并在下次就绪后恢复。有明确范围的其他数值也改用滑块，支持 **Ctrl+点击**精确输入。

## 修复与性能改进

- 更新原生入口、反射契约和物品目录，生命读取、恢复生命与无敌改用新版原生接口；关闭无敌仅撤销修改器添加的状态。
- 修复紫色场景掉落漏识别、无效对象导致自动收集与高亮状态变为未知，以及范围变化后重复发起拾取的问题。
- 分批查询附近目标、优先处理近处物品，并限制提示创建数量；高亮最多显示当前已加载、游戏已登记的最近 **32 个**受支持目标。
- 移除修改器绘制的黄色圆点与悬浮文字，改用原生提示。图标异步加载，稳定显示时不反复查表、换图或播放入场动画。
- 减少周期维护中的重复工作，将性能日志写盘移出游戏线程，并分批处理物品目录与图片，降低周期卡顿和物品页集中加载开销。性能收益仍随场景和设备变化，不承诺固定 FPS 提升。
- 物品数量支持增加或设置，已适配道具可减量或清零；补齐独立书页、花瓣的本地化名称与分类，唯一类物品不重复发放。
- 修复 DX11 覆盖层部分着色器状态恢复及输入钩子衔接问题。

## 使用与已知范围

- 更新前保存并正常退出游戏。发行 ZIP 内含 Loader、`scripts/GlossTrainer.asi` 和双语安装说明；升级保留原有配置，并移出旧的 `scripts/PBZ.asi`，避免重复加载。
- 传送目标仍须是已激活铃铛。自动收集不会保证绕过所有交互条件；高亮不显示尚未加载的远处区域，也不提供 V 原界面的屏外贴边箭头，不影响手动 V 和任务追踪。
- 无限消耗品目前只保护已核对的穿行符。游戏新版已移除实现的旧 GM 操作会明确显示不可用。
- 原生绿色提示曾通过实机画面确认。部分已知物品在先前实测中仍显示通用图标，本版补充了奖励字段兼容；按物品选图及已开宝箱过滤的最终画面、关闭清理与密集场景性能仍待进一步实机验收。完整范围以[验证记录](https://github.com/GlossMod/GlossTrainer/blob/master/PhantomBladeZero/docs/verification.md)为准。
