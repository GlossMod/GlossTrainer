# 功能与操作

当前源码版本 v0.3.3 定义 64 项功能，并提供物品目录与传送工具；本次更新修复中文输入法接入，并新增自定义界面开关按键，延续原有游戏功能逻辑。旧版 44 项的名称及参考快捷键来源见 [功能来源](fling-reference/features.json)；这些参考快捷键不是本项目默认绑定。功能快捷键全部默认为空。静态目录、已接入入口和游戏内实际效果是不同层次的证据；新增功能的游戏内逐项效果、物品添加和传送结果仍待用户手测，见 [验证记录](verification.md)。精魄、法术、影神图删除操作当前在界面中禁用。

## 操作方式

- 界面开关默认 **Insert**，可在“设置 → 快捷键 → 修改”录制单键或 Ctrl / Shift / Alt 组合键，Esc 取消；“恢复默认”设回 Insert。菜单键不可清空，冲突时保留旧键并提示；禁用功能快捷键仍可开关菜单。隐藏菜单不关闭已经启用的功能。
- **Ctrl+Shift+Home** 切换功能快捷键总开关，也可在设置页操作；这不会关闭已启用的功能。该组合保留，不可绑定给功能。
- 功能快捷键默认全部未绑定。在“修改功能”页点击目标功能行的“设置”按钮开始录制；Esc 取消，Backspace 或 Delete 清除。按键冲突会拒绝保存，其他功能的绑定不受影响。绑定保存在 `scripts\GlossTrainer\hotkeys.ini`。
- 所有功能开关初始关闭，功能参数和开关不跨启动保存。主题、界面缩放和窗口位置保存在 `scripts\GlossTrainer\ui.ini`。
- “传送 → 坐标与地标”按场景分组，默认折叠；点击场景标题展开，或使用“全部展开 / 全部折叠”。搜索场景名或地标名会展开匹配组，清空搜索后恢复之前的折叠状态；场景筛选仍可选择没有地标的场景并进入其默认出生点。
- 搜索、书签名称等文本框统一接入系统中文输入法，候选位置跟随光标；关闭菜单或失焦会取消未完成的组合。输入法中英文模式由玩家切换，菜单不会每帧强制中文状态。
- 修改输入框只暂存。开关类参数第一次通过启用生效；功能已开启时，编辑后点击“应用”更新参数。
- 灵蕴、物品数量、经验和灵光点是一次性动作：点击“应用”或按快捷键后先排队，30 秒内打开对应背包、角色页面或触发对应数据刷新。界面显示“已在游戏数据更新时应用”才表示请求被消费；超时会取消，需重新申请。
- “等待游戏”表示还在捕获目标；“未支持”表示本构建没有找到唯一且验证通过的入口。输入数值或点击不可用项不会伪装成功。

## 物品与传送

“物品”页支持按名称或编号检索、选择数量，并对支持的目录条目发起添加或删除。静态目录包含 1,160 条记录、17 个分类，其中精魄 329、法术 74、影神图 203；这些数据来自本地参考样本，具体来源及缺失值见 [catalog 说明](xxj-reference/catalog-data.md)。添加请求在游戏接口就绪后排队处理；界面结果表示接口调用结果，不应当作存档已保存的证明。试用前备份存档。精魄、法术、影神图条目的删除操作当前禁用。法术添加与 `Card` 对各条目的实际结果仍待实机确认。选择影神图条目后，可单独选择故事阶段 0–5 和画像阶段 0–1；此操作只提交所选阶段，不承诺完整解锁。目录数量输入对法术、影神图的调用路径不适用，实际命令不携带该数量，不能据 UI 数值推断一次添加多少。

“传送”页提供坐标读取和瞬移、按场景 / 地标前往、保存 / 删除坐标书签、刷新对象列表后定位对象。数据目录包含 79 个场景及 298 个地标。按场景进入时使用游戏默认出生点；书签只保存坐标，坐标跳转不切换场景。场景切换可能影响当前流程；地标与对象列表是坐标候选，不保证每个地点在任意游戏版本或进度都可安全到达。传送及对象定位尚待 v0.3.0 游戏内手测。

功能快捷键不提供预置默认绑定；“完整列表”中的“未绑定”代表首次启动的默认状态，录制并保存后由用户绑定。当前界面开关组合（默认 Insert）与 Ctrl+Shift+Home 是保留的 UI / 全局快捷键，不属于 64 项功能绑定。菜单改用其他组合后，原 Insert 组合可以分配给功能。


## 生效与恢复

“隐藏游戏界面”会隐藏游戏 HUD 和游戏菜单，GlossTrainer 菜单仍可使用。关闭后恢复所记录的显示状态；某个界面正在切换、暂时恢复失败时，功能先关闭，再逐帧重试。原本隐藏或折叠的界面不会被主动显示。记录采用弱引用，销毁后的旧界面不会恢复到复用其地址的新对象。

“丹药效果无限时间”只跟踪启用后使用的丹药，关闭后继续正常倒计时。“连续跳跃”在空中每次重新按下空格触发一次。“自由视角”再次关闭后返回原玩家控制器；切换角色或场景会关闭扩展功能并尝试恢复临时状态。

多数属性通过真实玩家 getter 的返回值覆盖实现，关闭后停止覆盖。生命、法力、气力、棍势、元气和异常积累还在资源变更事件中处理。关闭无限资源会停止保护，不会撤销战斗期间已经发生的恢复。

生命、法力、气力上限，四种抗性，以及经验和灵蕴倍率共九项需要游戏的属性通知，因此分次借助真实气力更新事件应用。启用或关闭后可让角色正常移动、消耗或恢复气力，等待队列推进；关闭恢复同一玩家对象中的最新真实基值。启用期间收到的游戏自身基值更新会保留为新的恢复基准，避免把正常升级、装备或增益变化回滚到启用前。玩家对象销毁或替换后会丢弃旧对象快照，避免访问失效内存。

根器点数、货币、物品、经验和灵光点属于实际数据修改，关闭开关或菜单不会撤销已写入的数据，也不会回滚游戏存档。根器开关关闭仅停止后续强制写入。需要保留原进度时，应在试用这些编辑前备份自己的存档。

同类功能同时打开时，最高暴击率优先于编辑暴击率；一击必杀优先于伤害倍率，伤害倍率优先于伤害加成；防御倍率优先于伤害减免。取消优先功能后，仍开启的低优先功能继续生效。

“设置游戏速度”缩放进程内 `QueryPerformanceCounter` 的增长率，会影响调用该时钟的游戏逻辑、界面动画及其他组件；它和玩家动作速度、移动速度相互独立。关闭恢复计时增长率为 1 倍，不回退已流逝时间。

## 版本边界

当前基于 Steam build **21393610**，主 EXE SHA-256 为 `cba6127df85fe6aedf5a71b398f268c8a963c7b19582c3cac087462518358e9a`。特征采用运行时唯一匹配，属性 getter 来自真实调用链，不使用固定绝对地址。解析当前已观察的 Windows x64 Mono AOT 代码形态；其他编译形态、补丁或泛型入口需要重新核验。

参考包的静态脚本和元数据证明的是实现依据，不证明本项目逐项效果。最新游戏内验证范围以 [验证记录](verification.md) 为准。
